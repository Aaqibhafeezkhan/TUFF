# Code of conduct

Anyone should be able to ask a basic question, report a bug or send their
first pull request here without worrying about how they'll be treated.

**Do:** be kind and patient, especially with people new to Swift, Metal, ML
or open source. Criticize code and ideas, not people, and explain why.
Assume good intent and ask when something's unclear.

**Don't:** harass, insult or demean anyone, post sexual content or threats,
share someone's private information, or keep pushing a point after being
asked to stop.

This applies to issues, pull requests, Discussions and anywhere else that
represents TUFF.

If something bothers you, tell me (Rex Hall, [@rexmhall09](https://github.com/rexmhall09)).
To report privately, use [private vulnerability reporting](https://github.com/rexmhall09/TUFF/security/advisories/new)
and start the title with "Conduct"; only I can see those. Depending on what
happened, I might talk to the person, remove content, or ban them from the
project.

Based on the ideas in the [Contributor Covenant](https://www.contributor-covenant.org/).
