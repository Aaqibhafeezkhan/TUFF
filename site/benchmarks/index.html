Add your Mac. In TUFF, open Benchmarks, pick models and press Run, then Share on GitHub. Or run tuff bench --models gemma4 --share. You need a GitHub account to post.

What the numbers mean. Writes is decode speed on a short prompt. Reads prompt is how fast a ~1,500-token prompt is processed. First token is the wait for that prompt; follow-up is the same wait when TUFF reuses the earlier conversation. Grouped rows count each person once, using their median, so posting many times doesn't move a ranking.

Trust. community passed the automatic checks. verified was checked by a maintainer. held is waiting for a person to look. None of this proves a result is genuine; it makes casual mistakes and copies easy to catch. See how benchmarks work and every post.
